# Snek Game

## Introduction

**Snek Game** is a 2D Snake game developed in **Unity** using **C#**.

The game recreates the classic Snake experience, allowing players to control the snake using keyboard input, collect randomly spawning food to grow, and restart when colliding with obstacles.

---

## Features

* Implemented **grid-based snake movement and WASD input handling** using Unity's C# scripting system
* Developed **dynamic snake growth** using instantiated prefab segments that follow the previous segment's position
* Implemented **2D collision detection and randomized food spawning** using Unity colliders, object tags, and bounded coordinate generation

---

## Tech Stack

* **Frontend:** Unity 2D
* **Backend:** C#
